# Luis R. Tapia art gallery

Upload `index.html` to `shop/index.html` in the existing `archero455-cmyk/florida-caribbean-lens` repository. The gallery links to images already referenced in that repository root. Do not move it to another repository without also copying the artwork photos and adapting relative paths.

The official PayPal merchant cart is embedded (`7C7FBWG39APX6`). No artwork-specific checkout button is enabled yet because the exact correspondence between PayPal button IDs and painting titles has not been verified. Add each verified `<paypal-add-to-cart-button data-id="...">` for the matching artwork only.

After uploading, visit: https://archero455-cmyk.github.io/florida-caribbean-lens/shop/

This is a static GitHub Pages site. Confirm that GitHub Pages is enabled for the main branch. Verify product availability, prices, shipping and purchase functionality before promotion.
